Fase 1: Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.

Shared Hosting

Layanan hosting di mana satu server fisik digunakan secara bersama-sama oleh banyak pengguna. Sumber daya (CPU, RAM, disk) dibagi rata sehingga biayanya sangat murah, namun performa dan kontrol akses (root) terbatas.

Dedicated Server

Layanan penyewaan satu server fisik secara penuh khusus untuk satu pengguna saja. Memberikan performa maksimal, keamanan tinggi, serta kendali penuh (full root access), namun memerlukan biaya yang mahal.

Amazon Lightsail

Layanan VPS (Virtual Private Server) dari AWS yang dirancang praktis dan mudah digunakan dengan paket harga bulanan tetap. Cocok untuk pemula, website skala kecil-menengah, dan aplikasi sederhana.

Amazon EC2

Layanan komputasi cloud (IaaS) tingkat lanjut dari AWS yang sangat fleksibel dan skalabel. Pengguna bebas mengonfigurasi spesifikasi hardware, jaringan (VPC), dan keamanan dengan sistem bayar sesuai pemakaian.
